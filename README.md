REF Agent – Ecossistema de Emancipação
O REF Agent é um aplicativo Android criado para ajudar pessoas a organizarem suas finanças, assumirem o controle de seus recursos e conquistarem mais autonomia econômica no dia a dia.

Mais do que uma simples planilha de gastos, o app reúne em um só lugar o controle de entradas e saídas, o acompanhamento de dívidas, diagnósticos sobre a saúde financeira e um guia prático para acessar direitos e serviços públicos.

O que o app faz na prática
Visão Geral (Dashboard): Um painel claro para acompanhar o saldo atual, receitas e despesas logo ao abrir o aplicativo.

Controle de Lançamentos: Registro rápido de tudo o que entra e sai do bolso.

Fontes de Receita: Espaço dedicado para organizar e gerenciar de onde vem o dinheiro.

Histórico Completo: Consulta fácil para revisar, editar ou apagar movimentações antigas.

Diagnóstico Financeiro: Uma análise inteligente que mostra o quanto da renda já está comprometida e qual é a real capacidade de poupar.

Gestão de Dívidas: Ferramenta para cadastrar pendências, registrar pagamentos e acompanhar a evolução até a quitação.

Radar de Direitos: Atalho direto para informações e serviços oficiais do governo, ajudando o usuário a garantir benefícios a que tem direito.

Tecnologias utilizadas
Java: Linguagem principal por trás de toda a lógica do aplicativo.

XML: Utilizado para desenhar e estruturar as telas.

Android Studio: Ambiente onde o projeto foi construído e testado.

SQLite: Banco de dados local que garante que as informações fiquem salvas no próprio aparelho, mesmo sem internet.

Git e GitHub: Usados para versionar e hospedar o código.

Como rodar o projeto na sua máquina
Baixe este repositório ou faça um git clone.

Abra a pasta do projeto no Android Studio.

Espere o Gradle terminar de sincronizar as dependências.

Conecte um celular Android via USB (com a depuração ativada) ou inicie um emulador.

Clique no botão Run (ícone de play) e aguarde o app instalar.
